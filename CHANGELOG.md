# Что нового

## 1.0.1

- **Исправлено: чёрный экран вместо камеры.** Если детектор хоть на кадр терял лицо, появлялась ошибка «too many values to unpack» и кадр оставался чёрным навсегда.
- **Автообновление.** «Маска» сама проверяет новые версии. На Windows кнопка «Обновить» качает и ставит новую версию, а потом сразу её открывает. В пакете для Arch обновление ставится через pacman (спросит пароль). В портативной версии кнопка открывает страницу релиза.

## 1.0.0

Первый публичный выпуск.

- **Свои маски.** Картинка, GIF или видео встаёт на место лица и движется вместе с ним. PNG с прозрачностью ложится без фона, видео и GIF крутятся по кругу.
- Маска наклоняется вслед за головой (по линии глаз).
- Галерея «Мои маски»: добавить кнопкой «+» или перетащить файл в окно, удалить — правой кнопкой.
- Режимы размытия, пикселей и чёрной заливки, страховка «лица не видно — закрыт весь кадр».
- Виртуальная камера для Discord, OBS и браузера: v4l2loopback на Linux, камера OBS на Windows.
- Настройки и выбранная маска запоминаются между запусками.
- Сборки для Windows (установщик и портативная версия) и пакет для Arch Linux.
